DLLs: 
For the entry-level programmer, DLLs are a programming thing. In Microsoft land these have a dll extension (for dynamically linked library). You can create a program which contains methods/functions but without a main method. You can then compile this to a .dll.  It can't be run by itself, but  which you can then link it to other programs (ones with a main()) allowing you to call functions/methods from the .dll.
Most large programs work this way. (In Linux we use the .so extension.) It allows you to update part of an application (by replacing the faulty dll you need to patch, without out having to do a full re-install.
Example here:
